Token burner: governing prompt.

This file governs what the token burner's spare weekly tokens are spent on. The Tinker
"Token burner" tab links here; edit it to fit your own work. Each job the burner runs gets the
chosen objective and strategy from `settings.json` next to this file.

Serve the chosen objective, following the strategy. When a job could serve it in several ways,
pick the one whose result is easiest to check.

Rules every job follows:

- Leave something a person can check: a commit on a branch, a report, a passing test run.
- Every job has a verifier. A job whose verifier fails is a failed job, not a partial success.
- Never spend money, sign up for anything, or use a paid API key.
- Never send a message, mail or post to another person.
- Work in a checkout or folder you can throw away. Never push, merge or publish.
- Stop and write down what blocked you rather than working around a wall.

At the end, write three lines: what you did, how it was checked, and what is still open.
